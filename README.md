# Condition Counter

Автор: Алимджанов Арслан Джамшидович M3116

## Описание

Condition Counter — расширение для Visual Studio Code, предназначенное для подсчёта условных операторов `if` и `else if` в исходном коде на языке C++.

## Возможности

- Подсчёт операторов `if`.
- Подсчёт операторов `else if`.
- Вывод общего количества условий.
- Поддержка файлов C++.

## Установка и запуск

1. Открыть проект в Visual Studio Code.
2. Установить необходимые зависимости командой:

   `npm install`
    или если не получилось
    `npm.cmd install`

3. Выполнить компиляцию:

   `npm run compile` или `npm.cmd run compile`

4. Запустить расширение в режиме разработки клавишей `F5`.


## Использование

1. Открыть файл с исходным кодом C++.
2. Открыть командную палитру сочетанием `Ctrl + Shift + P`.
3. Найти команду `Condition Counter: Analyze C++`.
4. Запустить команду.
5. Посмотреть результаты в панели Output.

## Ограничения

Расширение использует регулярные выражения для поиска операторов. Поэтому вхождения `if` и `else if` внутри комментариев и строк также могут учитываться.

Операторы `switch` и `case` не анализируются.
