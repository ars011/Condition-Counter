# Техническое задание
## Разработка расширения Condition Counter для Visual Studio Code

### 1. Назначение программы

Condition Counter — расширение для Visual Studio Code, предназначенное для подсчёта условных операторов `if` и `else if` в исходном коде на языке C++.

### 2. Цель разработки

Создать расширение, которое автоматически анализирует открытый файл C++ и выводит количество найденных условных операторов.

### 3. Функциональные требования

Программа должна:
- Работать в Visual Studio Code.
- Поддерживать файлы с расширениями `.cpp`, `.cc`, `.cxx`, `.h`, `.hpp`, `.hh`, `.hxx`.
- Находить операторы `if` и `else if`.
- Подсчитывать количество каждого типа операторов.
- Выводить результаты в отдельную панель Output.

### 4. Требования к интерфейсу

Пользователь запускает анализ через командную палитру Visual Studio Code командой `Condition Counter: Analyze C++`.

### 5. Ограничения

Анализ выполняется с помощью регулярных выражений. Вхождения `if` и `else if` внутри комментариев и строк также могут учитываться. Операторы `switch` и `case` не анализируются.

### 6. Ожидаемый результат

Работающее расширение Visual Studio Code, которое подсчитывает условные операторы в открытом файле C++ и отображает результаты анализа.
