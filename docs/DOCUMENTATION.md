# Документация Condition Counter

## 1. Общая информация

Condition Counter — расширение для Visual Studio Code, предназначенное для подсчёта условных операторов `if` и `else if` в исходном коде на языке C++.

Расширение написано на TypeScript с использованием Visual Studio Code Extension API.

## 2. Структура программы

Основная логика расширения находится в файле `src/extension.ts`.

В программе используются следующие функции и компоненты:

- `activate()` — активирует расширение и регистрирует команду анализа.
- `registerCommand()` — регистрирует команду `condition-counter.analyze`.
- `activeTextEditor` — получает открытый в данный момент редактор.
- `document.getText()` — получает содержимое открытого файла.
- `createOutputChannel()` — создаёт отдельную панель для вывода результатов.
- `deactivate()` — выполняется при деактивации расширения.

## 3. Алгоритм работы

1. Пользователь запускает расширение.
2. Открывает файл с исходным кодом C++.
3. Запускает команду `Condition Counter: Analyze C++`.
4. Программа получает содержимое файла.
5. Проверяет формат файла.
6. С помощью регулярных выражений находит операторы `if` и `else if`.
7. Подсчитывает количество найденных операторов.
8. Выводит результат в панели Output.

## 4. Подсчёт условных операторов

Для поиска операторов используются регулярные выражения:

- `\bif\s*\(` — поиск оператора `if`.
- `\belse\s+if\s*\(` — поиск оператора `else if`.

Количество обычных операторов `if` определяется вычитанием количества `else if` из общего количества найденных `if`.

## 5. Вывод результатов

Результаты анализа отображаются в панели Output.

Пример:

```text
Файл: test.cpp
if: 2
else if: 1
Всего: 3
```

## 6. Ограничения программы

- Анализируются только файлы поддерживаемых форматов C++.
- Поиск выполняется с помощью регулярных выражений.
- Условия внутри комментариев и строк также могут учитываться.
- Операторы `switch` и `case` не анализируются.
