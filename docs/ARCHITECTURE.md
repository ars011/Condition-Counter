# Архитектура расширения Condition Counter

## 1. Последовательность работы

1. Пользователь открывает проект расширения в Visual Studio Code.
2. Пользователь запускает расширение в режиме разработки клавишей `F5`.
3. Открывается новое окно Visual Studio Code с загруженным расширением.
4. Пользователь открывает файл с кодом C++.
5. Пользователь запускает команду `Condition Counter: Analyze C++`.
6. Программа находит и подсчитывает операторы `if` и `else if`.
7. Результат отображается в панели Output.

## 2. Структура проекта

Основная логика расширения находится в файле `src/extension.ts`. Настройки и регистрация команды задаются в `package.json`.
